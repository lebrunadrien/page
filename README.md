# Portfolio 2026

Monsieur site portfolio simple avec thème bleu.

## 📁 Fichiers

- `index.html` - Page d'accueil
- `style.css` - Styles et design bleu
- `script.js` - Graphique 2026

## 🚀 Déploiement avec GitHub Pages

1. Allez sur: https://github.com/lebrunadrien/page/settings
2. Onglet **Pages** → Source: `main`
3. Votre site sera accessible à: `https://lebrunadrien.github.io/page`

## 🌐 Configuration du domaine OVH

**Dans l'espace client OVH:**
- Domaines > lebrunadrien.com > Zones DNS
- Créez un enregistrement `A` vers: `185.199.108.153`
- Créez un `CNAME` pour www vers: `lebrunadrien.github.io`

**Dans GitHub Settings > Pages:**
- Custom domain: `lebrunadrien.com`

Attendez 15 minutes à 48h pour la propagation DNS.

## 🎨 Personnalisation

Vous pouvez modifier:
- Les couleurs dans `style.css`
- Le contenu dans `index.html`
- Les données du graphique dans `script.js`
